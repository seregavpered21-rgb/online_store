# План развития магазина

Этот план разбит на небольшие этапы. Каждый следующий этап опирается на предыдущий, поэтому не стоит начинать оплату или админку до готовности каталога и заказа.

## 1. Определить правила магазина

- [ ] Утвердить название, домен, логотип и контактные данные. Временно: `Warenladen`.
- [x] Сформировать стартовые категории: одежда, аксессуары, подарки и новинки; палитра - тёплые цвета.
- [x] Определить доставку: самовывоз и доставка по Эссену, NRW; также отправка почтой по Германии.
- [x] Определить оплату для первой версии: при получении.
- [x] Подготовить временные тексты на немецком: о магазине, доставка, возврат и политика конфиденциальности.
- [x] Подготовить примерный каталог на немецком в `src/lib/catalog/sample-data.ts`; фото, остатки и точные описания будут уточняться.

## 2. Настроить окружения и базу данных

- [x] Подключить существующую Vercel Postgres / Neon базу: `DATABASE_URL` находится в локальном `.env.local`.
- [x] Добавить `DATABASE_URL` в переменные окружения Vercel.
- [x] Добавить отдельные схемы в `src/db/schema/`: `category`, `product`, `productCategory`, `variant`, `price`, `stock`, `image`.
- [x] Добавить схемы `customer`, `cart`, `cartItem`, `order` и `orderItem` в ту же папку.
- [x] Добавить связь товаров и категорий в `productCategory`.
- [x] Сгенерировать и применить первую миграцию Drizzle в `src/db/migrations/0000_quiet_jigsaw.sql`.
- [x] Создать и применить seed-скрипт с тестовыми категориями и товарами: `src/db/seed.ts`.
- [x] Добавить команды `db:generate`, `db:migrate` и `db:seed` в `package.json`.

## 3. Сделать каталог

- [ ] Перенести публичные маршруты в `src/app/(store)/`: главная, каталог, товар, категории, корзина и оформление.
- [ ] Вынести общие элементы витрины в `src/components/layout`, карточки в `src/components/product`, а элементы корзины в `src/components/cart`.
- [ ] Реализовать страницу списка товаров `src/app/(store)/products/page.tsx` с пагинацией.
- [ ] Реализовать страницы категорий `src/app/(store)/categories/[slug]/page.tsx` с описанием и FAQ.
- [ ] Реализовать карточку `src/app/(store)/products/[slug]/page.tsx` с фотографиями, описанием, ценой, наличием и похожими товарами.
- [ ] Добавить выбор варианта товара: размер, цвет или другой параметр.
- [ ] Добавить поиск, фильтрацию и сортировку каталога.
- [ ] Подключить реальные изображения через Next.js `Image` и настроить хранилище изображений.

## 4. Регистрация и роли

- [ ] Выбрать провайдера аутентификации: Auth.js, Clerk или Better Auth.
- [ ] Реализовать регистрацию, вход, выход и восстановление пароля.
- [ ] Создать таблицу пользователей и профиль покупателя.
- [ ] Добавить страницу `src/app/(store)/account/page.tsx`: имя, телефон, адреса, история заказов.
- [ ] Ввести роли `customer` и `admin`.
- [ ] Закрыть административные маршруты проверкой роли на сервере.

## 5. Корзина и оформление заказа

- [ ] Создать `cart` (`id`, `customerId`, `createdAt`) и `cartItem` (`cartId`, `productId`, `quantity`, `priceSnapshot`) для авторизованных покупателей.
- [ ] Реализовать гостевую корзину в cookie или localStorage с объединением после входа.
- [ ] Сделать `src/app/(store)/cart/page.tsx`: изменение количества, удаление, итоговая сумма.
- [ ] Сделать `src/app/(store)/checkout/page.tsx`: контакты, доставка, адрес, комментарий к заказу.
- [ ] Создать таблицы заказов и позиций заказа.
- [ ] Фиксировать цену и название товара в позиции заказа, чтобы история не менялась после редактирования каталога.
- [ ] Сделать страницу подтверждения заказа и письма покупателю и владельцу магазина.

## 6. Оплата и доставка

- [ ] Выбрать платёжный сервис, подходящий стране работы магазина: ЮKassa, Stripe или другой.
- [ ] Создать платёж только на сервере после валидации заказа.
- [ ] Добавить webhook оплаты и проверку подписи webhook.
- [ ] Менять статус заказа только по подтверждённому событию платёжного сервиса.
- [ ] Уменьшать остаток товара атомарно после подтверждения заказа.
- [ ] Интегрировать доставку или добавить ручную обработку заказов на первом этапе.

## 7. Админ-панель

- [ ] Создать маршруты `src/app/admin/products`, `src/app/admin/categories` и `src/app/admin/orders`.
- [ ] Добавить создание и редактирование товаров, вариантов, цен, остатков и изображений.
- [ ] Добавить загрузку фотографий в S3-совместимое хранилище, например Cloudflare R2.
- [ ] Добавить управление статусами заказов и заметки для продавца.
- [ ] Добавить экспорт заказов в CSV.
- [ ] Добавить журналирование важных действий администратора.

## 8. SEO, аналитика и качество

- [ ] Добавить функции title, description и canonical URL в `src/lib/seo`.
- [ ] Добавить компоненты JSON-LD в `src/components/seo`: `Organization`, `Product`, `BreadcrumbList` и `Category`.
- [ ] Добавить уникальные metadata и Open Graph для всех страниц.
- [ ] Создать `sitemap.ts` и `robots.ts`.
- [ ] Подключить аналитику с учётом требований к согласию на cookies.
- [ ] Настроить мониторинг ошибок, например Sentry.
- [ ] Написать тесты для расчёта корзины, стоимости заказа и прав доступа.
- [ ] Проверить адаптивность, доступность с клавиатуры и основные сценарии на телефоне.

## 9. Запуск и поддержка

- [ ] Настроить production-переменные окружения в Vercel.
- [ ] Подключить домен и настроить HTTPS.
- [ ] Настроить резервное копирование Neon и доступы команды.
- [ ] Прогнать оформление тестового заказа целиком: товар, корзина, оплата, письмо, статус.
- [ ] Написать короткую инструкцию для продавца по товарам и обработке заказов.
- [ ] Настроить регулярную проверку зависимостей и резервных копий.

## Первая рабочая версия

Минимально полезная версия магазина включает этапы 1-5: реальный каталог, вход покупателя, корзину и приём заказа. Онлайн-оплату, интеграции доставки и расширенную админку можно добавить после первых заказов.
