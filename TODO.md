# План развития магазина

Этот план разбит на небольшие этапы. Каждый следующий этап опирается на предыдущий, поэтому не стоит начинать оплату или админку до готовности каталога и заказа.

## 1. Определить правила магазина

- [ ] Утвердить название, домен, логотип и контактные данные. Временно: `Warenladen`.
- [x] Сформировать стартовые категории: одежда, аксессуары, подарки и новинки; палитра - тёплые цвета.
- [x] Определить доставку: самовывоз и доставка по Эссену, NRW; также отправка почтой по Германии.
- [x] Определить оплату для первой версии: при получении.
- [x] Подготовить временные тексты на немецком: о магазине, доставка, возврат и политика конфиденциальности.
- [x] Подготовить примерный каталог на немецком в `src/lib/catalog/sample-data.ts`; фото, остатки и точные описания будут уточняться.

## 2. Настроить окружения и базу данных

- [x] Подключить существующую Vercel Postgres / Neon базу: `DATABASE_URL` находится в локальном `.env.local`.
- [x] Добавить `DATABASE_URL` в переменные окружения Vercel.
- [x] Добавить отдельные схемы в `src/db/schema/`: `category`, `product`, `productCategory`, `variant`, `price`, `stock`, `image`.
- [x] Добавить схемы `customer`, `cart`, `cartItem`, `order` и `orderItem` в ту же папку.

- [x] Создать и применить seed-скрипт с тестовыми категориями и товарами: `src/db/seed.ts`.
- [x] Добавить команды `db:generate`, `db:migrate` и `db:seed` в `package.json`.

- [x] Реализовать страницу списка товаров `src/app/(store)/products/page.tsx`, подключённую к Vercel Postgres; пагинация нужна после появления большого каталога.
- [x] Реализовать страницы категорий `src/app/(store)/categories/[slug]/page.tsx`, подключённые к Vercel Postgres; FAQ добавить после согласования содержания.
- [x] Реализовать карточку `src/app/(store)/products/[slug]/page.tsx`, подключённую к Vercel Postgres, с описанием, ценой, вариантами и доступностью; похожие товары добавить позже.

## Первая рабочая версия

Минимально полезная версия магазина включает этапы 1-5: реальный каталог, вход покупателя, корзину и приём заказа. Онлайн-оплату, интеграции доставки и расширенную админку можно добавить после первых заказов.
